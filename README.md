# AI Workspace

**V1.0**

AI 직원을 고용하고 관리하는 워크스페이스입니다. V1.0의 첫 직원은 **AI 고객센터**입니다. 매장 휴대폰으로 오는 문자와 부재중 전화를 받아 문의에 답하고, 견적을 접수하고, 상담 일정을 잡습니다. 금액과 예외는 사람이 결정합니다.

워크스페이스에는 다음 직원이 앉을 빈 자리가 있습니다. 고객센터 한 명을 끝까지 운영할 수 있게 만든 뒤, 그 옆에 직원을 더하는 구조입니다.

## V1.0에서 되는 일

### 워크스페이스

로그인하면 오늘 출근한 직원과 비어 있는 자리가 보입니다.

- 출근 카드는 AI 고객센터입니다. 전화·문자를 맡고, 데스크로 들어갑니다.
- 옆의 세 자리는 비어 있습니다. 직원이 추가되면 이 화면에 앉습니다.
- 관리 화면과 관리 API는 이 컴퓨터에서만 열립니다. Cloudflare 터널로 들어온 요청은 휴대폰 웹훅만 통과합니다.

### 문자가 들어오면

휴대폰 문자는 MacroDroid 웹훅으로 받고, 설정하면 SMS Gateway for Android로 바꿀 수 있습니다. 같은 문자가 두 번 들어와도 한 번만 처리합니다.

처리 순서는 고정입니다.

1. 통신사 부재중 알림 문자인지 먼저 봅니다. 맞으면 고객 대화로 넘기지 않고 부재중 안내로 처리합니다.
2. 등록된 긴급 키워드가 있으면 AI 상담을 건너뛰고, 캘린더에 긴급 일정으로 올립니다.
3. 부재중 안내 뒤 고객이 1·2·3으로 답한 흐름이면, 그 접수 시나리오를 이어 갑니다.
4. 그 외 문자는 필터를 통과한 뒤 AI에게 갑니다.

필터에서 거는 것은 아래와 같습니다.

- AI 근무가 중지된 상태
- 빈 문자
- 한국 휴대폰 번호가 아닌 발신
- 제외번호 시트의 번호
- 테스트 번호가 지정된 경우, 그 목록 밖의 번호
- 광고, 수신거부, 국외발신 문구
- 인증번호, 본인확인, 승인번호 같은 시스템 문자
- 같은 번호에 한 시간 동안 너무 많이 보낸 경우

고객이 문자를 여러 통으로 끊어 보내면, 설정된 초만큼 모았다가 한 턴으로 합칩니다. 기본은 45초입니다.

### AI 고객센터가 상담에서 하는 일

Claude가 지식베이스와 이 고객의 이전 견적·일정만 보고 답합니다. 한 번에 질문은 하나, 문자 길이로 짧게 답합니다. 첫 응대에서는 AI임을 밝히고, "네", "감사합니다"처럼 답이 필요 없는 말에는 보내지 않습니다.

상담 중에 실제로 호출하는 기능은 다음과 같습니다.

| 기능 | 하는 일 |
| --- | --- |
| 문의 분류 | 견적, 예약, 변경, 취소, 일반, 불만, 기타와 한 줄 요약을 남깁니다. 매 응답마다 기록합니다. |
| 고객 정보 저장 | 이름, 주소, 선호처럼 고객이 말한 내용을 고객 시트에 남깁니다. |
| 견적 접수 | 서비스, 상세, 장소, 희망 일정이 모이면 견적 요청을 만듭니다. 금액은 말하지 않습니다. |
| 빈 시간 조회 | 캘린더에서 예약 가능한 시간을 찾습니다. 시간을 제안하기 전에 조회합니다. |
| 일정 확정 | 고객이 시간을 골랐을 때만 상담, 방문견적, 작업 중 하나로 등록합니다. |
| 일정 변경·취소 | 이 고객 일정만 옮기거나 취소합니다. |
| 담당자 이관 | 불만, 환불, 가격 협상, 지식베이스에 없는 질문, 사람을 찾는 경우 관리자에게 넘깁니다. |

모델이 다른 고객의 번호를 넣어도 통하지 않습니다. 도구는 지금 대화 중인 번호에 고정되어 있습니다.

보내기 직전에 코드가 한 번 더 검사합니다.

- 600자를 넘는 답장
- 할인, 환불, 보상, 무료 진행, 결과 보장 약속
- 링크
- 지식베이스나 확정 견적에 없는 금액

막히면 그 답은 버리고, 담당자가 확인 후 연락하겠다는 문구로 바꿉니다. 원래 답과 사유는 텔레그램으로 갑니다.

### 견적

AI는 접수까지만 합니다. 관리자가 금액과 내용을 입력하면 상태가 `견적완료`가 되고, 2분마다 도는 작업이 고객에게 문자를 보냅니다. 보낸 뒤에는 `견적발송`으로 바뀝니다.

견적 상태 흐름은 `견적대기` → `견적완료` → `견적발송` → `일정확정` 또는 `종료`입니다.

### 부재중 전화

벨을 못 받았거나, 통신사 부재중 알림이 오면 안내 문자를 보냅니다. 문구는 운영 설정에서 켜고 끄거나 고칠 수 있습니다. 같은 번호에는 10분에 한 번만 보냅니다. AI 근무를 멈춰도 부재중 안내만은 따로 나갈 수 있습니다.

고객이 번호를 고르면 시나리오가 갈라집니다.

1. 중고차 성능보증 수리·점검. 차량 번호, 차종, 보증보험사, 증상을 받습니다.
2. 일반 정비·견적. 차량 번호, 차종, 요청사항을 받습니다.
3. 지인·개인 통화. 용건을 받습니다.

접수가 끝나면 구글 시트 `접수메모`에 남기고, 마지막 문자 시각으로부터 1시간 뒤에 캘린더 일정을 만듭니다. 데스크에는 아직 연락하지 않은 접수 건수가 배지로 뜹니다. 조치상태를 바꾸면 배지에서 빠집니다.

### 긴급 문자

협회·보험처럼 바로 봐야 하는 키워드가 본문이나 발신 이름에 있으면 AI 상담을 타지 않습니다. 캘린더에 긴급 일정을 만들고 문의 로그에 `사장님확인필요`로 남깁니다. 키워드 목록은 `app/urgent_keywords.py`에 있습니다.

### 야간·새벽

운영 설정에서 제한 시간을 둡니다. 기본 예시는 00:00부터 09:00입니다. 그 시간에 들어온 긴급 일정과 부재중 후속 일정은 다음날 종료 시각으로 미루고, 고객에게는 그때 연락하겠다는 문자를 보냅니다.

### 예약 작업

서버가 켜져 있는 동안 세 가지가 반복됩니다.

- 2분마다, 작성된 견적을 고객에게 발송
- 설정한 시각(기본 18시)에, 내일 일정이 있는 고객에게 리마인드 문자
- 설정한 시각(기본 21시)에, 오늘 받은 메시지 수, AI 답장 수, 견적 대기 목록을 텔레그램으로 보고

### 관리 화면

| 화면 | 하는 일 |
| --- | --- |
| 직원 데스크 | 오늘 문의, AI 처리, 견적 대기, 예정 일정, 근무 상태. 고객 인박스에서 전화·문자를 거르고 검색합니다. 데스크톱과 모바일 레이아웃이 따로 있습니다. |
| 고객 대화 | 번호별 대화를 보고, 관리자가 그 번호로 직접 문자를 보냅니다. 대화 초기화도 있습니다. |
| 전체 활동 | 기간을 정해 들어온 문의와 일정을 봅니다. |
| 접수 메모 | 부재중 이후 접수 내용을 보고 조치상태를 바꿉니다. |
| 운영 설정 | 구글·문자·텔레그램 연동 상태, DRY RUN, 테스트 번호, 시간당 발송 한도, 문자 묶음 대기, AI 근무 중지, 야간 제한, 부재중 안내 문구, 지식베이스. |
| 계정 관리 | 관리자 계정을 추가하고 비밀번호를 바꿉니다. |
| 테스트 채팅 | 고객 휴대폰 화면처럼 문자를 넣고, 부재중 전화와 통신사 알림을 시뮬레이트합니다. 실제 필터를 켜고 끌 수 있습니다. |

DRY RUN이 켜지면 고객 휴대폰 대신 텔레그램에 보낼 내용만 갑니다. 테스트 번호를 비우면 필터를 통과한 모든 번호에 응답합니다.

### 기록이 나뉘는 곳

구글 시트는 사람이 보고 고치는 장부입니다. 탭은 고객, 문의로그, 견적, 일정, 지식베이스, 제외번호, 설정, 접수메모입니다.

SQLite는 AI의 작업 메모리입니다. 대화 원문, 이미 처리한 이벤트, 근무 중지와 운영 정책 플래그가 여기 있습니다. 시트에서 고친 지식베이스와 설정은 짧은 캐시 뒤에 반영됩니다.

## 구성

```
app/
  main.py                 웹훅, 관리 API, 화면, 터널 차단
  service.py              수신부터 발송, 견적, 리마인드, 일일 보고
  agent/                  프롬프트, Claude 도구, 발송 전 검사
  integrations/           문자, 구글 시트, 구글 캘린더, 텔레그램
  static/                 워크스페이스와 데스크 화면
tests/                    필터, 인증, 부재중, 견적, 정책
scripts/check_google.py   시트·캘린더 연결과 탭 생성
```

스택은 Python, FastAPI, Claude, SQLite, Google Sheets, Google Calendar, Telegram, APScheduler입니다.

## 실행

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`.env`에 Claude API 키와 웹훅 토큰을 넣습니다. 시트와 캘린더 없이 화면과 대화 흐름만 보려면 `MOCK_MODE=true`로 둡니다. 이 모드는 재시작하면 메모리 내용이 사라집니다.

구글 연동은 서비스 계정 JSON을 `credentials/service-account.json`에 두고, 시트와 캘린더를 그 계정에 공유한 뒤 확인합니다.

```bash
python -m scripts.check_google --init
pytest
```

`.env`, `credentials/`, `data/`는 저장소에 없습니다. 첫 실행 때 생기는 로컬 관리자 계정은 배포 전에 `app/main.py`에서 바꾸세요.
